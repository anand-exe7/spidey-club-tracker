# 🕸️ CodeKrafters Launchpad (Spidey Tracker)

Welcome to the **CodeKrafters Launchpad**! This is the official retro, pixel-art inspired onboarding platform for the CodeKrafters club. Designed with a distinct "Spidey Tracker" aesthetic, the platform features a cinematic dark mode, interactive radar telemetry, and a sleek presentation of our club domains and executive leadership.

## 🚀 Features

- **Spidey Tracker Dashboard**: A live-simulated telemetry terminal showcasing club sprints, commits, and activity logs alongside a working radar scanner.
- **Club Domains Showcase**: A smooth carousel highlighting all 7 core domains (Dev, Web3, CP, Content, PR, etc.) and their respective Leads/Heads.
- **Interactive UI/UX**: Custom CSS grid layouts, animated pixel-art spiders, and "Thwip" sound effects built directly into the UI.
- **Responsive Design**: Flawless glassmorphic design and grid structures optimized for both mobile devices and widescreen displays.

## 🛠️ Tech Stack

- **Framework**: [TanStack Start](https://tanstack.com/start) (React)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Components**: [Radix UI](https://www.radix-ui.com/) & Custom Animations
- **Build Tool**: [Vite](https://vitejs.dev/)

## 📦 Getting Started

### Prerequisites

Ensure you have **Node.js 20+** and **npm** installed on your machine.

### Installation

1. **Clone the repository**
   ```sh
   git clone https://github.com/your-org/spidey-club-tracker.git
   cd spidey-club-tracker
   ```

2. **Install dependencies**
   ```sh
   npm install
   ```

3. **Run the development server**
   ```sh
   npm run dev
   ```

4. Open your browser and navigate to the local URL provided in your terminal.

## 🔨 Building for Production

To create an optimized production build:

```sh
npm run build
```

This will bundle the client and server assets, outputting them into the `.output` directory.
